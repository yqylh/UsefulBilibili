# usefulbilibili

一个面向哔哩哔哩（Bilibili）的统一油猴效率脚本。

## 仓库目标

- 用一个脚本覆盖动态页和收藏页的常用收藏操作。
- 尽量使用 B 站接口完成操作，减少对页面菜单和文案的依赖。
- 默认不接管原生收藏列表，只有选择具体分区后才显示自定义结果。

## 脚本清单（Script Index）

| 脚本名（油猴显示） | 文件路径 | 适用页面 | 核心功能 |
|---|---|---|---|
| `[Bilibili] 收藏与收藏夹效率工具` | `scripts/bilibili/bilibili-favorites-toolkit.user.js` | 动态页、收藏夹页 | 一键收藏、快捷取消收藏、分区筛选、批量取消收藏 |

## 使用前准备

1. 浏览器安装 Tampermonkey（或同类用户脚本管理器）。
2. 保持 B 站已登录状态（部分接口/操作依赖登录 Cookie）。
3. 如果此前安装过本仓库的三个旧脚本，请先禁用或删除旧脚本，避免重复注入按钮。

## 安装方式

1. 打开 Tampermonkey 控制面板。
2. 新建脚本。
3. 将 `scripts/bilibili/bilibili-favorites-toolkit.user.js` 的内容粘贴进去并保存。
4. 刷新对应 B 站页面，确认脚本已生效。

## 详细功能与用法

### 动态页：封面一键收藏

- 在 `t.bilibili.com` 动态流中，为视频封面注入 `★` 悬浮按钮。
- 点击 `★` 可直接把视频加入目标收藏夹，无需打开视频详情页。
- 首次使用会自动保存列表中的第一个自建收藏夹作为目标。
- `Shift + 点击` 按钮可弹窗切换目标收藏夹。
- 页面滚动懒加载、动态新增内容也会自动注入按钮。

使用步骤：

1. 打开 B 站动态页：`https://t.bilibili.com/`。
2. 将鼠标移动到视频封面右上角，点击 `★`。
3. 看到“已收藏”提示即表示成功。
4. 如需切换收藏夹：按住 `Shift` 再点击 `★`，按提示输入序号。

### 收藏页：快捷取消收藏

- 在本账号创建的收藏夹视频卡片上显示“取消收藏”按钮。
- 点击后直接调用收藏接口，不再模拟打开菜单和点击确认按钮。
- 订阅收藏夹、他人的公开收藏夹不会显示删除入口，避免误操作。

使用步骤：

1. 打开自己的收藏夹列表页。
2. 点击目标卡片右上角的“取消收藏”。
3. 接口完成后卡片会从当前列表移除。

### 收藏页：分区筛选与批量管理

- 在收藏夹页面顶部注入“分区筛选”下拉框。
- 默认保持 B 站原生列表不变；只有选择具体分区后，脚本才接管列表区域。
- 通过收藏夹接口的 `tid` 参数重新拉取结果，而不是仅对当前已渲染卡片做前端隐藏。
- 支持上一页 / 下一页翻页，切回“全部分区”或点击“返回原列表”即可恢复 B 站原生视图。
- 自建收藏夹和订阅收藏夹都可以进行分区筛选。
- 只有本账号创建的收藏夹会显示单个和批量取消收藏入口。

使用步骤：

1. 打开收藏夹列表页：`https://space.bilibili.com/<uid>/favlist`。
2. 在列表上方找到“分区筛选”下拉框。
3. 选择例如“游戏 / 动画 / 知识”等分区。
4. 页面会切换为脚本渲染的筛选结果视图。
5. 在自己的自建收藏夹中，可以点击“批量取消收藏”后勾选视频并执行删除。
6. 如需退出筛选，选择“全部分区”或点击“返回原列表”。

注意事项：

- 脚本使用收藏夹接口按分区重新请求数据，排序固定为“按收藏时间”。
- 只在你明确选择某个分区时接管列表，尽量减少对原生页面的影响。
- 筛选视图下会隐藏 B 站原生批量管理按钮，避免与脚本自己的批量取消收藏入口冲突。

## 实现与权限说明

- `GM_xmlhttpRequest`：访问 `api.bilibili.com` 的收藏接口。
- `GM_getValue / GM_setValue`：保存动态页快速收藏的目标收藏夹。
- 操作依赖登录态中的 `bili_jct` 与 `DedeUserID` Cookie。
- 脚本不会在订阅收藏夹或他人收藏夹中调用删除接口。
